# Demo Guide

## Local Demo Target
Use this target first because it is safe and controlled:

```text
http://127.0.0.1:8000
```

## Recommended Demo Steps

1. Run the server with `./start.ps1`.
2. Open `http://127.0.0.1:8000`.
3. Choose the `Quick` or `Web` scan profile.
4. Click `Run Scan`.
5. Explain open ports, missing headers, risk score, and report export.

## Ethical Note
Do not scan public websites unless you own them or have permission.
