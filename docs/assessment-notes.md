# Assessment Notes

Santhosh SecureScan is designed for learning vulnerability assessment basics.

## What It Detects
- Open TCP ports
- Risky exposed services
- Basic service banners
- Missing HTTP security headers
- Plain HTTP usage
- TLS certificate expiry hints
- Outdated-looking software version banners

## Limitations
- It does not exploit vulnerabilities.
- It does not replace enterprise scanners.
- Version findings are hints and should be verified manually.
